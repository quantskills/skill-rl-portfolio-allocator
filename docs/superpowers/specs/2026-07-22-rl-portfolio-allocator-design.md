## 1. 目标与核心洞察

用强化学习(PPO)学习**动态因子权重分配**,在沪深300成分股上生成多空组合,reward 为风险调整后收益(差分 Sharpe DSR + 回撤/换手/集中度惩罚),而非累计收益。

**核心洞察**:不让 RL 在 300 维股票权重上直接学(维度灾难),而是让 RL 学 **K 个量价因子的权重**(约 5-8 维),再用确定性层把因子权重 → 综合得分 → Top-N/Bottom-M 选股 → 多空持仓。本质是 **RL 驱动的动态因子择时 (dynamic factor timing)**,组合权重是其副产品。

### 数据流

```
                          ┌─────────────── 每个交易日 t ───────────────┐
沪深300成分股 ──► 计算 K 个量价因子打分 (横截面标准化)
                          │         │
                          │         ▼
   RL State ◄─────────────┤    因子暴露矩阵 F_t (300 × K)
   (波动状态+相关性+       │         │
    因子暴露+持仓)         ▼         │
                    PPO Policy       │
                          │          │
                          ▼          ▼
              动作 a_t = tanh → L1归一化 ── 因子权重 w_t (K维, Σ|wᵢ|=1, 可正可负)
                                     │  → EMA 平滑 w̃_t
                                     │
                                     ▼
                    综合得分 s = F_t · w_t  (300维)
                                     │
                                     ▼
              Top-N 做多 + Bottom-M 做空 + 组内得分加权 → 目标权重 p_t
                                     │
                                     ▼
        交易环境: 施加换手成本+融券成本+冲击 → 实现净收益 r_t
                                     │
                                     ▼
                Reward = 差分 Sharpe DSR(净收益) − 回撤/换手/集中度惩罚
```

## 2A. 动作空间(详细定义)

RL 的动作**只有 K 维因子权重**;敞口(多头/空头/现金)由确定性规则控制,不进动作空间。这让"RL 到底学到了什么"完全可解释——只有因子权重在动。

### 2A.1 从原始动作到因子权重

```
raw_action a_t ∈ R^K                          # PPO policy 输出 (连续)
tanh 激活    ã = tanh(a_t) ∈ [-1, 1]^K         # 可正可负 → 允许"反向使用某因子"
L1 归一化    w_t = ã / (Σ|ãᵢ| + eps)            # Σ|wᵢ| = 1, 权重可正可负
EMA 平滑     w̃_t = α · w_t + (1-α) · w̃_{t-1}     # α 超参, 硬性降换手, 与换手惩罚互补
```

- **可正可负**:tanh 使因子权重能取负值,RL 可学"某 regime 下反转某因子"(如高波动期给动量因子负权重 = 反动量)。
- **L1 归一化**(`Σ|wᵢ|=1`)而非 softmax:softmax 恒正且和为1,无法表达因子反向;L1 归一化保留符号。
- **EMA 平滑**:防止因子权重逐日剧烈跳变导致巨额换手。`α` 越小越平滑。

### 2A.2 从因子权重到持仓(确定性层)

```
综合得分   s_t = F_t · w̃_t                      # F_t: 300×K 因子暴露矩阵(横截面标准化)
剔除停牌   停牌股先从选股池剔除
选股       多头 = Top-N(s_t),  空头 = Bottom-M(s_t)
组内权重   多头名义 = 100%(组内按得分加权),  空头名义 ≤ 30%(组内按得分加权)
现金       cash = 1 − (多头名义 + 空头名义占用)
```

- **敞口固定**:多头 100%、空头上限 30%、现金 = 剩余,均为确定性规则,RL 不学敞口。
- 空头名义 > 0 时才产生融券成本(见 §3.1)。

## 3. 交易环境(成本模型 + State + Reward)

任务反复强调:训练环境须内嵌**交易成本 + 借券成本 + 冲击**。

### 3.1 成本模型(内嵌进环境 step)

持仓从 `p_{t-1}` 调到目标 `p_t`,环境扣三类成本:

| 成本 | 公式 | 默认参数 |
|---|---|---|
| 交易成本 | `commission × Σ\|p_t − p_{t-1}\|`(双边换手) | 佣金 3bps + 印花税(卖出侧)10bps |
| 冲击成本 | MVP 线性 `impact × turnover`;可切非线性 `impact × Σ(\|Δpᵢ\|)^1.5` | 5bps × turnover |
| 融券成本 | 仅对空头:`borrow_rate × Σmax(−pᵢ, 0) × Δt` | 年化 8% 按日折算 |

**A股约束**:
- 允许融券做空,但**空头总仓位设上限**(如 ≤ 30% 或 ≤ 多头名义)。
- 简化"可融券池"(MVP 全池可融,可后续标记不可融标的)。
- 保证金占用 MVP 简化为空头名义的固定比例。
- 现金维度 = `1 − (多头名义 + 空头名义占用)`。

### 3.2 State(严格对齐"波动状态 + 相关性 + 因子暴露")

全部只用 t 日及以前信息:

| 分量 | 内容 | 维度 |
|---|---|---|
| 波动状态 | 组合近20/60日已实现波动率、市场(300指数)波动率、波动率分位数(regime) | ~4 |
| 相关性 | 成分股滚动窗口平均两两相关性 | ~2 |
| 因子暴露 | 当前持仓在 K 个因子上的加权暴露 + 各因子近期 IC | ~2K |
| 持仓状态 | 上期 EMA 平滑因子权重 `w̃_{t-1}` + 现金比例 + 近期换手率 | ~K+2 |

总维度约 20-30,PPO 完全可处理。

### 3.3 Reward(差分 Sharpe DSR + 惩罚项)

**主项:差分 Sharpe (Differential Sharpe Ratio, Moody & Saffell 1998)**。不用"整窗口 Sharpe"——那会让同一段收益反复领奖、credit assignment 糊掉。DSR 用指数移动的一阶矩 A、二阶矩 B 在线更新,每步只反映"本期收益对 Sharpe 的边际贡献":

```
A_t = A_{t-1} + η·(R_t − A_{t-1})              # 收益一阶矩 (EMA)
B_t = B_{t-1} + η·(R_t² − B_{t-1})             # 收益二阶矩 (EMA)
DSR_t = (B_{t-1}·ΔA − ½·A_{t-1}·ΔB) / (B_{t-1} − A_{t-1}²)^1.5
        其中 ΔA = R_t − A_{t-1}, ΔB = R_t² − B_{t-1}
```

- `R_t` = **扣完全部成本(佣金+印花税+冲击+融券)后的组合净日收益**。成本自然被学习,与"环境内嵌成本"一致。禁止用毛收益。
- `η` 为 DSR 的 EMA 衰减率(超参),对应有效窗口 ≈ 1/η。
- 可选切换 Sortino 风格:二阶矩只累计下行收益 `min(R_t, 0)²`,由环境参数控制。
- **代码层面禁止用累计收益 (cumret) 做 reward。**

**复合 reward(DSR 主项 + 三惩罚项)**:

```
r_t = DSR_t
    − λ_dd   · max(0, drawdown_t)              # 回撤惩罚 (针对压力测试 MDD 目标)
    − λ_to   · Σ|w̃_t − w̃_{t-1}|                 # 换手惩罚 (与 EMA 平滑互补)
    − λ_conc · HHI(p_t)                         # 集中度惩罚 (赫芬达尔指数, 鼓励分散)
```

**务实告诫(务必写进实现)**:四个系数(`η, λ_dd, λ_to, λ_conc`)的权衡是本项目最难调的部分。惩罚项过重会让 agent 退化成"躺平不交易"(换手0、回撤0、但也无 alpha)。因此:
- **λ 默认值先设小,以 DSR 为主导**;逐步加大惩罚观察行为。
- **将"agent 是否退化成躺平/空仓"列为强制训练诊断项**:监控年化换手率、平均持仓数、多空敞口利用率——若接近 0 则判定退化,需调小 λ。

## 4. 数据切分与压力测试

### 4.0 三类训练用途(必须区分,不可混用)

同一套方法(env + PPO + reward)服务于**三个不同的训练目标**,训练窗口和用途各异。关键纪律:**压力/回测模型绝不能用来生产;生产模型绝不能留样本外尾巴。**

| 用途 | 训练窗口 | 评估/输出 | 脚本 | 场景 |
|---|---|---|---|---|
| ① 压力测试 | 各压力段**之前**(如测2020只训到2019) | 前向该压力段,评估极端市况 MDD/Sharpe | `stress_test.py` | 研究 |
| ② 历史主回测 | 早期(如 2010–2022) | 样本外 2023+,常规市况业绩 | `backtest.py` | 研究 |
| ③ **生产模型** | **数据起点 ~ 最新可得日(无样本外尾巴)** | 输出最新一期持仓 | `allocate.py` | 生产 |

**为什么生产模型"吃到今天"不是作弊**:作弊是"回测时偷看未来";生产恰恰要用尽可能新的历史来预测未来,没有 out-of-sample 尾巴可留。生产模型的可信度由 ① ② 的样本外结果**背书**——先用 ①② 证明这套方法在样本外可行,再用同样的方法 + 全部数据训练 ③ 用于实盘。

**生产模型的重训节奏(retrain cadence)**:训练贵、推理便宜,故解耦为两种模式:
- **定期重训**(如每月/每季):用"数据起点 ~ 最新日"全部数据重训生产 PPO 模型,落盘 checkpoint。
- **每日推理**:两次重训之间,每天加载同一生产模型 + 当日最新特征,输出当日持仓(不重训)。
- `allocate.py` 支持 `--retrain`(重训生产模型)和 `--infer-only`(仅用现有生产模型推理)两种模式;二者训练目标独立于 ①②。

### 4.1 训练跨度策略(用途①):扩展窗口 + 前向压力段

**纪律**:每段压力测试的训练窗口只含该段**之前**的连续数据 → 因果无泄漏、无未来函数、不破坏时序连续性。放弃"从训练集中间挖掉压力段"的做法(会给出虚假的严谨感,且无法区分"策略不行"与"没见过该 regime")。

| 前向压力段 | 训练窗口(连续,只到"训练截止日") | 前向样本外测试(交易日闭区间) | 核心段(必看) | 数据风险 |
|---|---|---|---|---|
| ① 2008 全球金融危机 | 数据起点 ~ **2007-06-30** | **2007-07-01 ~ 2009-03-31** | **2008-09-01 ~ 2009-03-31**(雷曼后崩盘 + A股大熊尾段) | ⚠️ 高(数据可能不足 → 跳过) |
| ② 2015 中国股灾 | 数据起点 ~ **2015-05-31** | **2015-06-12 ~ 2015-09-30** | 同 test 全段(千股跌停 + 停牌潮) | 中(需停牌处理) |
| ③ 2020 疫情冲击 | 数据起点 ~ **2020-01-31** | **2020-02-19 ~ 2020-04-30** (A 股 2020-01-23 春节休市起可视为 regime 起点,交易日从 2020-02-03 复市) | 同 test 全段 | 低 |
| ④ 2022 股债双杀 | 数据起点 ~ **2021-12-31** | **2022-01-01 ~ 2022-12-31** | 同 test 全段(俄乌 + 疫情慢熊) | 低 |

- agent 会"见过"更早的危机(如 2020 的训练集含 2015),符合真实部署。
- 代价:4 段 = 4 次(独立)PPO 训练,但小 agent 训练不贵。
- **核心段**:除报告全 test 段指标外,再额外报告"核心段"内的 ARR / MDD / Sharpe / Calmar,便于观察 regime 最恶劣子区间的表现。
- **常规样本外主回测(用途②)**:如训 2010-01-01 ~ 2022-12-31、测 2023-01-01 起,作为非极端市况的主回测。
- **段①(2008)数据不足则明确报告并跳过,不伪造、不用其他段替代;要求 `train_end - data_start ≥ 3 年`,否则跳过。**

### 4.2 停牌处理(2015 段必需)

停牌股当日不可调仓,权重冻结到复牌;综合得分里停牌股剔出选股池。不做则 2015 回测失真。

### 4.3 每段压力输出

ARR / MDD / Sharpe / Calmar / 最大单日回撤 / 空头贡献 / 换手率 / 融券成本占比,并与等权基线、纯多头基线对比,验证 RL 在极端市况下是否真的降低回撤。

## 5. 回测指标(对齐 DLTX 仓库口径)

### 研究口径
- 组合层:`ARR(%)` / `MDD(%)` / `Sharpe` / `Sortino` / `Calmar(CR)` / 年化波动 / 胜率
- 多空分解:多头收益 / 空头收益 / 多空对冲收益
- 换手与成本:年化换手率 / 交易成本占比 / 融券成本占比 / 冲击成本占比
- 因子择时诊断:RL 学到的因子权重时间序列(可视化,验证不同 regime 是否真的切换因子)

### 可交易口径
- `data_lag=1日`(t 日信号 t+1 执行)
- 全成本开启(佣金+印花税+冲击+融券)
- 报告 `tradeable_ARR` / `tradeable_Sharpe`

### 基线对比(必须在风险调整指标上显著优于)
1. 等权组合(1/N)
2. 纯多头 Top-N(不做空、不择时)
3. 静态因子等权(因子权重固定不学,隔离"RL择时"的增量价值)

RL 组合需在 **Sharpe/Calmar** 上显著优于三个基线 —— 注意是风险调整,不是绝对收益。

## 7. 运行流程(对齐 DLTX Agent 执行规则)

```bash
python scripts/features.py               # 1. panda_data → 因子表 (报告日期范围/品种数/因子维度)
python scripts/train.py                  # 2. PPO 训练核心自检 (报告收敛曲线/最终reward/训练设备)

# --- 研究口径 (用途①②) ---
python scripts/backtest.py               # 3. 主回测: 训早期→测样本外, 研究+可交易口径, 三基线对比
python scripts/stress_test.py            # 4. 四段前向压力测试 (每段训该段之前, 含停牌处理)

# --- 生产口径 (用途③) ---
python scripts/allocate.py --retrain     # 5a. 定期重训: 用数据起点~最新日全部数据训生产模型, 输出最新一期持仓
python scripts/allocate.py --infer-only  # 5b. 每日推理: 加载现有生产模型 + 当日特征, 输出当日持仓 (不重训)
python scripts/validate.py               # 6. 规范性校验 (不通过不得进入生产)
```

**训练目标区分**:`backtest.py`(②)、`stress_test.py`(①)、`allocate.py`(③)各自独立训练,窗口不同、用途不同。生产只用 `allocate.py` 产出的模型和持仓表,其可信度由 ①② 的样本外结果背书。

运行前需设置 `PANDA_DATA_USERNAME` 和 `PANDA_DATA_PASSWORD`。可选 `PANDA_DATA_START_DATE`、`PANDA_DATA_END_DATE`、`RL_ALGO`(默认 ppo)、`REWARD_TYPE`(sharpe/sortino)、`RETRAIN_CADENCE`(生产重训节奏,如 monthly/quarterly)、`TRAIN_DEVICE`(auto/cuda/mps/cpu)。

## 8. 验收标准(硬性)

- **无未来函数**:t 日因子只用 t 及以前量价;t 日建仓 t+1 计收益;压力段训练窗口只含该段之前数据。
- **Reward 是差分 Sharpe (DSR) + 惩罚项**,**非累计收益** —— 代码层面禁止用 cumret 做 reward;DSR 输入为扣全成本净收益。
- **动作空间是 K 维因子权重**(tanh + L1归一化,可正可负,EMA平滑);敞口为确定性规则,不进动作空间。
- **训练诊断必做**:监控换手率/平均持仓数/敞口利用率,判定 agent 是否退化成躺平空仓(若是则调小惩罚系数 λ)。
- **成本内嵌**:交易成本+融券成本+冲击必须进环境 step,回测报告各成本占比。
- **压力测试必做**:四段前向输出 ARR/MDD/Sharpe/Calmar;2008 数据不足则明确报告并跳过(不伪造)。
- **基线对比**:RL 组合在风险调整指标(Sharpe/Calmar)上显著优于 ①等权 ②纯多头TopN ③静态因子等权。
- **数据源**:panda_data,不读本地表作正式输入。不记录/提交凭据。
- **停牌处理**:2015 段停牌股权重冻结、剔出选股池。
- **测试**:pytest 覆盖环境不变量(权重和=1、空头≤上限)、成本计算正确性、无未来函数断言。
- **三类训练不可混用**:压力测试(①,训段前)、主回测(②,训早期测样本外)、生产模型(③,吃到最新日)各自独立;压力/回测模型不得用于生产,生产模型不得留样本外尾巴。
- **生产模型可产出最新一期持仓**:`allocate.py --retrain` 用数据起点~最新可得日全部数据训练;`--infer-only` 复用现有生产模型每日推理;可信度由 ①② 样本外结果背书。
- **双模式**:生产查询只读已落盘结果,不重训、不重算。
